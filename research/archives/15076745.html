【驚愕】Claude Opus 5.5、最新の最高峰モデルなのに実は「前世代より安くなった」件ｗｗ

 

AIの新モデルと聞けば、だいたい想像するのはこれだ。

 

「また賢くなったのか」

 

「で、どうせ高いんだろ？」

 

ところが2026年9月22日にAnthropicが発表したClaude Opus 5.5は、その順番を少しおかしくしてきた。

 

性能を上げた。

 

長時間の仕事にも強くした。

 

出力速度も上げた。

 

そして――前世代のClaude Opus 5より安くした。

 

Anthropicによれば、Claude Opus 5.5のAPI価格は100万トークンあたり入力4ドル、出力20ドル。Opus 5の入力5ドル、出力25ドルから、それぞれ20％安くなっている。さらにトークン効率などを含む典型的な処理では、Opus 5より約40％低コストになるという。

普通は新型が出たら「性能アップしたのでお値段もアップしました」が自然である。

 

こいつ、値札まで逆方向へ進化している。

 

今回は、公開されたばかりのClaude Opus 5.5が何を変えたのか。そしてなぜ「安くなった」という話が単なる値下げ以上に面白いのかを見ていく。

 

📜 第一章　最高峰モデルなのに、値札が下がった

Claude Opus 5.5は、Anthropicが2026年9月22日に発表したClaude 5.5ファミリー最初のモデルだ。

 

公式には、長時間実行されるエージェント型コーディングとナレッジワーク向けのモデルとして位置づけられている。コンテキストウィンドウは100万トークン、通常の最大出力は128Kトークンだ。

 

そして目を引くのが価格である。

 

Opus 5は100万入力トークン5ドル、100万出力トークン25ドルだった。

 

Opus 5.5はそれぞれ4ドルと20ドル。

 

つまり単価だけなら20％下がった。さらにキャッシュ読み込みは100万トークン0.50ドルから0.20ドルへ下がり、こちらは60％減となる。

 

「最高峰モデルを更新しました！」

 

ここまでは分かる。

 

「ついでに安くしました！」

 

そこは普通、逆じゃないのか。

 

しかもAnthropicが強調しているのは単純な値下げだけではない。Opus 5.5は同じ仕事を終えるまでに使うトークンそのものも減らせるため、デフォルト設定での典型的な処理コストはOpus 5より約40％低いとしている。

 

ここは数字を混同しないほうがいい。

 

「API料金が40％値下げされた」のではない。

 

トークン単価は20％低下。効率向上まで含めた典型的な処理コストが約40％低下という話だ。

 

しかも生成速度はOpus 5より30％以上高速化したとAnthropicは説明している。さらに別料金のFast modeでは最大2.5倍の速度を選択できる。

 

高性能化したから重く、高くなる。

 

そんな分かりやすい進化ではなかった。

 

「同じ仕事なら、もっと少ない計算資源と金で終わらせる」こと自体が今回の性能向上に入っている。

 

📜 第二章　68万行を相手にして「長時間働くAI」へ

では安くした代わりに能力を削ったのか。

 

Anthropicの発表を見る限り、狙っている方向はむしろ逆である。

 

Opus 5.5で特に強調されているのが、短い質問に一回答えて終わる仕事ではなく、長時間にわたって複数の工程を進める仕事だ。

 

その象徴として紹介されている早期テスターの事例がなかなか物騒である。

 

あるテスターは、68万行規模のコード移行を1日未満で完了したという。

 

Anthropicは、人間のエンジニアチームなら数週間かかる規模だったと説明している。

 

別のテストでは20万行のコードベースを監査・修正し、3時間未満で終了。Opus 5では20時間以上かかり、使用トークンも2.5倍だったという。

 

もちろん、ここは注意が必要だ。

 

これは「Claude Opus 5.5ならどんな68万行のプロジェクトでも1日で終わる」という保証ではない。早期テスターやAnthropicによる特定条件での事例である。

 

それでも、Anthropicが新モデルを何に使わせようとしているかはかなり分かりやすい。

 

昔ながらのチャットAIなら、

 

人間「これ直して」

 

AI「直しました」

 

人間「じゃあ次これ」

 

という往復だった。

 

Opus 5.5が狙っているのは、その「じゃあ次」を大量にまとめて任せる方向である。

 

長いコードベースを読み、変更し、確認し、必要なら別の処理へ進む。

 

AIが「回答する道具」から「しばらく仕事を預ける相手」へ寄っている。

 

そのため100万トークンという巨大なコンテキストも、単に「長い文章を読めます」というだけではない。

 

大規模なコードや大量の資料を抱えたまま仕事を続けるための作業机でもある。

 

机がデカい。

 

しかも前より使用料が安い。

 

大家は何を考えている。

 

🧩 つまり、どういうこと？

Opus 5.5の面白さは、「性能が何％上がった」という一点ではない。

 

高性能モデルを、長時間動かしても現実的なコストへ近づける方向に設計されているところにある。

 

賢さ、速度、トークン効率、単価。

 

この四つをまとめて改善し、「高性能AIは高すぎて大仕事には使いづらい」という壁を削ろうとしているわけだ。

 

📜 第三章　そして「考えない」という設定まで消えた

Opus 5.5には、価格以上に妙な変更がもう一つある。

 

Adaptive ThinkingをOFFにできない。

 

Anthropicの公式ドキュメントでは、Opus 5.5のAdaptive Thinkingは常時有効とされている。

 

Opus 5では条件によってthinking: disabledを指定できたが、Opus 5.5で同じ指定をすると400エラーになる。

 

つまり開発者は、

 

「今回は考えなくていい」

 

と完全停止させるのではなく、

 

「今回は軽めに考えてくれ」

 

「これは重要だから深く考えてくれ」

 

という調整をする。

 

その役割を担うのがeffortだ。

 

Opus 5.5ではAdaptive Thinkingが常時動き、思考の深さ・遅延・コストをeffortで調節する。デフォルトはmediumで、5段階のeffortを利用できる。

 

考えるか、考えないか。

 

ではない。

 

どれくらい考えるか。

 

AIにまで勤務態度の調整表が導入された。

 

しかもこれは単なるUI上の変更ではなく、Opus 5から移行する開発者には破壊的変更となる。

 

Opus 5.5では思考OFFだけでなく、特定ツールを強制的に使わせる一部の指定もエラーになるなど、既存コードに影響する変更が複数ある。

 

つまり「モデル名だけ5から5.5へ書き換えれば全部終了」とは限らない。

 

安くなったからと喜んで差し替えたら、

 

API「その設定もう受け付けません」

 

となる可能性がある。

 

値札は優しくなったが、引っ越し業者ではない。

 

🍶 歴史板、今夜もざわつく

新モデル発表を眺めていた三人の古参AIウォッチャーが、また余計なところに引っかかった。

 

🍶 トークン代を気にする元SE： いや待て。新しいOpusが前より安いって、昔のパソコンなら「新型CPU出ました、速いです、しかも安いです」みたいな話だろ。旧型買った直後の人が一番複雑な顔するやつ。

 

🏮 定年後もAPI叩く爺： でも単価20％減と実行コスト40％減は分けて考えんといかんぞ。40％値下げしたわけじゃない。そこ雑に書いた記事、たぶん明日には増える。

 

🍵 仕様書だけは全部読む男： ワシは値段より「thinkingをdisabledにしたら400エラー」のほうが気になる。AIに「今日は考えなくていい」が通用せん。

 

🍶 トークン代を気にする元SE： 会社員時代のワシより勤務意識高いな。

 

🏮 定年後もAPI叩く爺： お前はeffort lowだっただけだ。

 

🍵 仕様書だけは全部読む男： しかもデフォルトmediumだぞ。

 

🍶 トークン代を気にする元SE： 新人の初期設定に負けた。

 

🪭 仕様から見える、意外な素顔

① 「最高性能＝最高価格」とは限らなくなった

Opus 5.5はAnthropicのOpus系最新モデルでありながら、Opus 5よりトークン単価が低い。

 

しかもAnthropicは単価だけでなく、仕事を終えるまでに必要なトークン数を減らすことを強く訴求している。

 

これは生成AIの競争軸が、「一問あたりどれだけ賢いか」だけではなくなっていることを示している。

 

長時間AIを働かせるなら、能力が少し高いだけでは足りない。

 

同じ仕事を何回の呼び出し、何トークン、何ドルで完了できるか。

 

請求書までベンチマークになってきた。

 

② 100万トークンは「長文自慢」だけではない

Opus 5.5のコンテキストウィンドウは100万トークンで、1回のリクエストから最大128Kトークンを出力できる。

 

大規模なコードベース、長い調査資料、多数のファイルを扱うエージェントでは、「途中まで覚えていた前提が落ちる」ことが仕事の継続性を壊す。

 

だから100万トークンという数字は、単に小説を大量に読ませるためだけのものではない。

 

長時間仕事をさせるなら、机だけでなく記憶を置いておく棚も必要になる。

 

Opus 5.5、オフィスだけ妙に広い。

 

③ 安くしたのに、安全評価まで増やした

AnthropicはOpus 5.5について、約2000シナリオを扱う自動行動監査で、最近のClaudeモデルと比較して多くの不整合行動指標で最良の結果だったとしている。

 

また、Frontier DesignやMETRなど外部評価者によるリリース前評価も実施した。

 

ただし、これは「絶対に安全」という意味ではない。

 

Anthropic自身も限界が残ることを明記している。

 

性能が上がった。

 

価格は下がった。

 

長時間動くようになった。

 

だからこそ「長時間勝手に変なことをしないか」という評価の重要性も増している。

 

便利になった分だけ、放置したときの責任範囲も広がる。

 

🌱 Claude Opus 5.5が変えようとしているもの

一つ目は、高性能モデルの価格感覚だ。

 

Opus 5.5はOpus 5より入力・出力単価を20％下げた。キャッシュ読み込みについては60％低下している。

 

二つ目は、AIとの仕事の単位だ。

 

一問一答ではなく、数時間、場合によってはそれ以上続く仕事を任せる。そのために長いコンテキスト、エージェント性能、トークン効率をまとめて改善する。

 

三つ目は、思考量の扱いだ。

 

Opus 5.5ではAdaptive Thinkingを完全停止するのではなく、effortによって思考の深さを調整する。

 

「AIを使う」から、

 

「この仕事には、どの程度のAI労働を割り当てるか」へ。

 

少なくともOpus 5.5の設計思想を見る限り、境目はそこへ動き始めている。

🐾 猫じろうの歴史ちょこっと授業

トークン

AIが文章を処理するときの単位。

 

日本語の「1文字＝1トークン」ではないので、文字数と完全には一致しない。API料金はこのトークン量を基準に計算されることが多い。

 

コンテキストウィンドウ

AIが一度の処理で参照できる情報量の上限。

 

Opus 5.5は100万トークン。長い会話だけでなく、大量の資料やコードを抱えながら作業する用途でも重要になる。

 

キャッシュ

同じ長い情報を何度もAIへ渡す仕事では、毎回すべてを処理し直すと金も時間もかかる。

 

そこで以前の入力を再利用する仕組みが重要になる。Opus 5.5ではキャッシュ読み込み価格が100万トークン0.20ドルとなり、Opus 5より60％低くなった。

 

effort

Opus 5.5で「どれくらい深く考えるか」を調整する設定。

 

Adaptive Thinkingそのものは常時有効で、effortを上下させて速度・コスト・思考量のバランスを変える。標準設定はmediumだ。

 

これだけ覚えておけばいい。

 

Opus 5.5は「高性能化したから高くなったモデル」ではなく、「高性能なAIをもっと長く、安く働かせる」方向へ振ったモデルだ。

 

新型なのに安い。

 

速くなったのに安い。

 

長時間働けるようになったのに安い。

 

そして「今日は考えなくていい」と言うとエラー。

 

最後だけ妙に頑固である。
